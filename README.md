# Scheda V4 — PWA

App: **https://marcobaldini94.github.io/scheda-v4/**

Tracker di allenamento installabile (rotazione A-B-C). I file in radice sono quelli serviti da GitHub Pages; `sorgenti/` contiene il codice React per ricompilare. Istruzioni complete in [ISTRUZIONI.md](ISTRUZIONI.md).

## Aggiornare
1. Modifica i file, **cambia la stringa `CACHE` in `sw.js`** (es. `scheda-v4-4.0.1`).
2. `git add -A && git commit -m "descrizione" && git push`
3. Dopo 1-2 minuti l'app installata mostra l'avviso di nuova versione. I dati sul telefono non vengono toccati.
